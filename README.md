# 🎓 Career Guidance AI

A **Streamlit** application that recommends career paths based on your resume
summary, skills, or interests.

It runs in two clearly separated modes:

- **AI mode**: with `OPENAI_API_KEY` configured, suggestions are generated by an
  LLM tailored to your input.
- **Demo mode**: without a key, the app runs fully offline with curated
  suggestions and shows a demo-mode banner. If the AI service fails, the app
  automatically falls back to demo suggestions and tells you so.

## Features

- Resume/skills input with validation and clear error messages
- AI-powered career suggestions with rationale (OpenAI provider)
- Offline demo mode and automatic failure fallback (results never fabricated as "AI")
- Session history with Markdown and JSON export
- Loading, empty, error, and success states throughout the UI
- Structured logging and environment-based configuration
- Unit-tested core logic and CI pipeline (lint + tests)
- Docker image for production deployment

## Architecture

```
├── app.py                     # Streamlit UI (pages: Guidance, History, About)
├── career_guidance/           # Core package (UI-agnostic)
│   ├── config.py              # Settings & logging (env-based)
│   ├── models.py              # Domain models & exceptions
│   ├── providers.py           # Pluggable backends: OpenAI + offline demo
│   ├── suggestions.py         # Validation & guidance orchestration + fallback
│   └── history.py             # Session history & export
├── tests/                     # Unit tests (pytest)
├── requirements.txt           # Runtime dependencies
├── requirements-dev.txt       # Development dependencies
├── pyproject.toml             # Packaging & tool configuration
├── Dockerfile                 # Container image for deployment
├── .env.example               # Documented environment variables
└── .gitlab-ci.yml             # CI pipeline (lint, test)
```

The UI never talks to external APIs directly; it calls `generate_guidance`,
which validates input, selects a provider, and handles failures. New providers
(other LLMs, a rules engine, a REST API) can be added by implementing
`SuggestionProvider`.

## Requirements

- Python 3.10+

## Setup

```bash
git clone https://gitlab.com/avenger-claude-group/career_guidance_llm_app.git
cd career_guidance_llm_app
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # then edit values as needed
```

## Run the app

```bash
streamlit run app.py
```

## Configuration

All configuration is via environment variables (see `.env.example`).
**Never commit real API keys.**

| Variable                 | Default       | Description                                        |
| ------------------------ | ------------- | -------------------------------------------------- |
| `APP_ENV`                | `development` | Deployment environment name                        |
| `LOG_LEVEL`              | `INFO`        | Logging verbosity                                  |
| `MIN_INPUT_LENGTH`       | `3`           | Minimum accepted input length                      |
| `MAX_INPUT_LENGTH`       | `10000`       | Maximum accepted input length                      |
| `OPENAI_API_KEY`         | *(empty)*     | Enables AI mode; empty = offline demo mode         |
| `OPENAI_MODEL`           | `gpt-4o-mini` | Model used for AI suggestions                      |
| `OPENAI_TIMEOUT_SECONDS` | `30`          | Timeout for AI requests                            |

## Deployment

### Streamlit Community Cloud (simplest)

1. Connect the repository at https://share.streamlit.io
2. Select `app.py` as the entry point.
3. Add `OPENAI_API_KEY` (optional) under app **Secrets**.

### Docker (Render, Railway, Fly.io, any container host)

```bash
docker build -t career-guidance-app .
docker run -p 8501:8501 --env-file .env career-guidance-app
```

Configure environment variables through your platform's secret management,
not in the image or repository.
